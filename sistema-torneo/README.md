# Sistema del Torneo

Proyecto independiente para el sistema de gestión del torneo.

Vive en su propia carpeta para no mezclarse con las herramientas existentes
de Keeper Cup 3 (`index.html` y `tools/` en la raíz del repositorio).
Nada de este directorio se enlaza desde esas herramientas ni depende de ellas.

## Estructura

```
sistema-torneo/
├── README.md     # este archivo
└── index.html    # punto de entrada del sistema
```
