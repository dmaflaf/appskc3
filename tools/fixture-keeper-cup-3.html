Fase de grupos: todos contra todos. 8 equipos por grupo, 7 fechas, cada equipo enfrenta una vez a cada rival de su grupo. Las Fechas 1, 2 y 3 ya se jugaron (estadio, día y horario reales); las Fechas 4-7 se generaron para completar el todos-contra-todos sin repetir cruces y se pueden editar.

Cómo usarlo: cada partido tiene dos casillas para el marcador — tócalas para anotar el resultado apenas se juegue (se guarda solo, en este dispositivo). En fechas por jugar (4-7), toca el nombre de un equipo para cambiarle el rival. Las Fechas 1 a 3 muestran estadio, día y horario reales; con ese dato ya puedes ver en Balance de estadios si hay igualdad entre San Miguel y Los Sauces.
